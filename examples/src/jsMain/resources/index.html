kmp-marine-api in the browser

The same parsing code the JVM, Node, macOS and Android demos run — compiled to WebAssembly-free JavaScript, reading NMEA fetched over HTTP rather than off a disk. There is no filesystem here, so the demo wraps the fetched bytes in a Buffer and hands that to the identical common code.
